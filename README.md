# RevMine: Empire Excavation

RevMine is a mobile-friendly HTML5 idle mining game prototype with a black, orange, and white RevEmpire-style theme.

## Play

Open `index.html` in a browser, or host the folder with any static web server.

## Included Systems

- RevCoin and Premium RevCoin balances
- Automatic mining and tap mining
- Miner upgrade tiers
- Electricity costs
- Rising network difficulty
- Miner wear and repair
- Power and cooling upgrades
- Rewarded ad placeholder buttons
- Offline earnings up to 8 hours
- localStorage save/load
